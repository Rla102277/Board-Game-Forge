2. ❌ WORKFLOW FRICTION (D Grade)
My desired workflow:
STEP 1: Create deck (5 min)
  → Name: "Spell Deck" (50 cards)
  → Subtypes: Spell, Artifact, Ritual (3 categories)

STEP 2: Add cards (30 min)
  IDEAL:
  - Inline form: Type name → Hit Enter → Card added
  - See card appear in list below
  - Continue adding without page reloads
  
  ACTUAL:
  - Click "New Card" button
  - Fill form (name, subtype, description, lore, notes)
  - Hit [Add Card]
  - Form clears
  - Card appears in list (sometimes)
  - Click "New Card" again
  - Repeat 50 times

STEP 3: Edit properties (20 min)
  IDEAL:
  - Click card → See inline property editor
  - "Cost: [3] Power: [5] Cooldown: [1]"
  - Edit right there
  
  ACTUAL:
  - Click card to open sheet view
  - Scroll to Properties tab (in card detail)
  - Click "Add Property"
  - Select property type
  - Set value
  - Save
  - Back to list
  - Repeat 150 times (50 cards × 3 properties)
Current flow: 10 clicks, 3 page loads, 1 form per card
Ideal flow: Inline editing, card appears instantly, no page reloads
Grade: D — Features exist but workflow is slow
Problems:

❌ No inline editing on the card list
❌ Form doesn't stay open for rapid card creation
❌ Properties hidden on separate tab
❌ No "bulk property assignment" (set all Cards to Cost: 2)
❌ No keyboard shortcuts (Tab to next field, Enter to submit)

Fix needed: Redesign for rapid iteration:

Inline card name editor on list
Click to expand → see properties inline
Tab moves to next card
No page reloads
