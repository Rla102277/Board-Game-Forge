## Process-Based Navigation with Advanced Mode Toggle

**Status:** Design Requirements Document  
**Date:** May 2, 2026  
**Purpose:** Transform navigation from category-based to process-based, with optional advanced mode

## 4. STAGE UNLOCK LOGIC

### Completion Calculation

```
Stage Completion % = (Completed Checklist Items / Total Items) * 100

Stage 1 Checklist:
  ✅ Name game (1)
  ✅ Choose players (1)
  ✅ Set duration (1)
  ⏳ Pick genre (1)
  ⏳ Research (optional - doesn't count)
  
  Completed: 3/4 = 75% → Can unlock Stage 2

Unlock Rule:
  - Show "Ready for Stage 2?" button when ≥ 70%
  - Allow jump to Stage 2 when unlocked
  - Show warning if jumping early
```

### Lock/Unlock Behaviors

- [ ] Stage 1 always unlocked (starting stage)
- [ ] Stage N unlocked when Stage N-1 ≥ 70%
- [ ] Can override lock in Advanced Mode (show warning)
- [ ] Can return to any previous stage
- [ ] Can pause a stage and come back

## 6. ADVANCED MODE SPECIFICATION

### Toggle Location & Behavior

```
Header: [Normal Mode] [Advanced Mode ▼]
```

**When Normal Mode (Default):**
- [ ] Show only current stage + 2 next stages
- [ ] Hide all tabs except current stage tabs
- [ ] Show checklists and guidance
- [ ] Show "Next Step" prompts
- [ ] Sidebar collapses on mobile
- [ ] Right sidebar shows Design Advisor

**When Advanced Mode:**
- [ ] Show all 6 stages in sidebar
- [ ] Show all tabs under each stage
- [ ] Hide checklists and guidance
- [ ] Hide "Next Step" prompts
- [ ] Sidebar expanded
- [ ] Right sidebar shows Design Advisor + Chat only
- [ ] Allow jumping to any stage (no locks)

**Toggle State:**
- [ ] Persists in localStorage
- [ ] User preference remembered
- [ ] Show "first-time" tooltip when mode switches

## 7. MOBILE RESPONSIVENESS

### Layout Rules

**Small Screens (<768px):**
- [ ] Header: Single line, game name + %, Advanced toggle
- [ ] Sidebar: Icon-only (left hamburger menu)
- [ ] Stage panel: Full width
- [ ] Right sidebar: Bottom drawer or hidden
- [ ] Progress bar: Horizontal scroll or collapsed

**Medium Screens (768px - 1024px):**
- [ ] Header: Full
- [ ] Sidebar: Collapsed by default, expandable
- [ ] Stage panel: 70% width
- [ ] Right sidebar: Hidden by default, toggleable
- [ ] Progress bar: Full

**Large Screens (>1024px):**
- [ ] Header: Full
- [ ] Sidebar: Always visible
- [ ] Stage panel: 60% width
- [ ] Right sidebar: Always visible
- [ ] Progress bar: Full

## 8. INTERACTION SPECIFICATIONS

### Navigation Actions

| Action | Normal Mode | Advanced Mode |
|--------|------------|----------------|
| Click stage name | Jump to stage (if unlocked) | Jump to stage |
| Click tab | Show tab content | Show tab content |
| Collapse header | Minimize to 1-line | N/A |
| Expand right panel | Always visible | Toggle |
| Back button | Return to current stage | Return to current tab |
| Keyboard shortcuts | Alt+N = next step | Alt+# = stage # |

### Tab Transitions

- [ ] Sticky header remains visible
- [ ] Game brief context preserved
- [ ] Design Advisor updates for new tab
- [ ] Save form data before leaving tab
- [ ] Show "Unsaved changes" warning if navigating away

└─ theme

### Persistence

- [ ] Navigation state in localStorage
- [ ] Game data in database (no change)

## 15. CONTENT SPECIFICATION

### Stage 1: Conceptualize - Help Text

**Game Overview Step:**
```
GAME OVERVIEW
Define what your game is about.

YOUR GAME'S NAME
Choose a memorable name. You can change it anytime.
Example: "Spell Collector", "Tide Pools", "The Last Station"

PLAYERS
How many people will play?
2-4 is good for starting. You can test different counts later.

DURATION
How long does a game take?
45 minutes is a good starting point. Balance games often take longer.

GENRE
What's the feel of your game?
Cooperative = Players work together
Competitive = Players compete
Hybrid = Mix of both
```

**Game Brief Step:**
```
MECHANIC FINGERPRINT
Rate your game across 5 dimensions.

LUCK (Random vs. Deterministic)
High luck games: Dice rolling, card draws
Low luck: Pure strategy (like chess)

STRATEGY (Simple vs. Complex)
High strategy: Many decisions, branching paths
Low strategy: Limited choices

INTERACTION (Solitary vs. Engaging)
High interaction: Players affect each other
Low interaction: Parallel play (everyone does their own thing)

COMPLEXITY (Easy vs. Deep)
High complexity: Long rules, high learning curve
Low complexity: Pick up in 5 minutes

THEME (Immersive vs. Abstract)
High theme: Story, flavor, narrative
Low theme: Abstract mechanics (numbers on cards)
```

## SUMMARY

This specification transforms Board-Game-Forge from a category-based tool (30 tabs, overwhelming) into a **process-based workflow** where:

1. **Normal Mode (Default):** Guided 6-stage process, checklists, "next steps" prompts
2. **Advanced Mode:** All tabs visible, no locks, no guidance
3. **Progression:** Clear path from concept → playable in 60 min
4. **Context:** Game brief always visible (sticky header)
5. **Guidance:** Design Advisor central, not hidden

**Key Metric:** Time to first playable game: 120+ min → 60 min
